# 📚 Product Landing Page

AuraBook is a modern and responsive **product landing page** designed for a personal study companion. It presents the product, its key features, testimonials, and contact information through a clean and professional interface.

This project is created using **only HTML5 and CSS3**.

---

## 🌟 Project Overview

**AuraBook – Personal Study Companion** is a conceptual study-product website designed to help students organize their learning activities.

The landing page introduces AuraBook and highlights its major features such as:

* Digital Notes
* Task Management
* Progress Tracking
* Smart Calendar
---

## ✨ Features

### 📝 Digital Notes

Create and organize study notes in one place.

### ✅ Task Management

Manage assignments, homework, and study tasks.

### 📊 Progress Tracking

Monitor study progress and academic goals.

### 📅 Smart Calendar

Plan study sessions, classes, and important academic activities.
